Installer Boire & Manger

Tes courses, tes recettes, ta cave et tes souvenirs de table, sur ton téléphone. Compte 10 minutes. Tes données restent dans un espace privé à toi : personne d’autre ne les voit.

  1. Crée un compte GitHub

    C’est gratuit, sur github.com/signup. Si tu en as déjà un, passe à l’étape suivante. Note ton nom d’utilisateur : il servira à l’étape 5.

  2. Crée ton dépôt de données, privé

    Va sur github.com/new :

    • Repository name : boire-et-manger-data
    • Coche Private
    • Ne coche rien d’autre, puis Create repository.

  3. Crée un jeton d’accès à ce seul dépôt

    Va sur github.com/settings/personal-access-tokens/new :

    • Token name : Boire & Manger, et une date d’expiration (par exemple dans un an)
    • Repository access : Only select repositories → boire-et-manger-data
    • Permissions → Repository permissions → Contents : Read and write
    • Generate token, puis copie le jeton (il commence par github_pat_). GitHub ne le montre qu’une fois : garde-le dans tes notes le temps de l’étape 5.

  4. Installe l’app sur ton téléphone

    Ouvre robaromat.github.io/boire-et-manger, puis :

    iPhone dans Safari

    1. Touche le bouton Partager : le carré avec une flèche vers le haut, en bas de l’écran (en haut sur iPad).
    2. Fais défiler et touche Sur l’écran d’accueil.
    3. Touche Ajouter.

    Android dans Chrome

    1. Touche le menu ⋮ en haut à droite.
    2. Touche Installer l’application (selon la version : « Ajouter à l’écran d’accueil »).
    3. Confirme avec Installer.

    L’icône B&M apparaît sur ton écran d’accueil. L’app s’ouvre en plein écran et marche aussi sans réseau.

    Sur iPhone, l’app installée ne reprend pas ce qui a été fait dans Safari : fais bien l’étape suivante depuis l’icône B&M.

  5. Ouvre l’app et connecte-toi

    Depuis l’icône B&M :

    • Jeton GitHub : colle ton jeton
    • Propriétaire : ton nom d’utilisateur GitHub
    • Dépôt : boire-et-manger-data

    Le champ « Propriétaire » est pré-rempli avec robaromat : remplace-le par ton nom d’utilisateur, sinon la connexion échoue.

    Touche Se connecter. L’app te dit que le dépôt est vide : touche Créer le fichier. C’est prêt.

  6. Facultatif

    Ajoute une clé OpenAI pour les fonctions ChatGPT

    Pour lire une recette ou une étiquette de vin en photo, « Challenger la recette » et « Donne-moi des infos » sur un vin :

    • Crée une clé sur platform.openai.com/api-keys et mets quelques euros de crédit (Billing)
    • Dans l’app : Réglages (en haut à droite) → colle la clé.

    Compte environ 1 centime par lecture. La clé reste sur ton téléphone.

Bon à savoir

  • Tes listes, recettes, vins et photos sont rangés dans ton dépôt privé : personne d’autre n’y a accès.
  • Le jeton et la clé OpenAI restent sur ton téléphone ; ne les envoie à personne.
  • Sur un autre appareil (tablette, ordinateur), refais les étapes 4 et 5 avec le même jeton : tout se synchronise.
  • L’app se met à jour toute seule : un bandeau « Mettre à jour » apparaît quand une nouvelle version sort.
  • Quand ton jeton expire, recrée-en un (étape 3) et colle-le dans les Réglages.
